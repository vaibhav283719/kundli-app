# Kundli App

This is the initial repository structure for the Kundli App.

## Project Overview
The Kundli App will provide users with functionalities related to generating and interpreting their astrological charts.

## Features
- User-friendly interface for entering birth details.
- Generating Kundli (astrological chart).
- Interpretation of astrological charts and related insights.

## Technologies Used
- Frontend: React, HTML, CSS
- Backend: Node.js, Express
- Database: MongoDB

## Getting Started
1. Clone the repository.
2. Install dependencies using `npm install`.
3. Start the application using `npm start`.
